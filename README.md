# תמלול פגישות – מדריך התקנה ושימוש

כלי חינמי להקלטה ותמלול פגישות בעברית (ובאנגלית). הכול רץ על המחשב שלך, ושום דבר לא נשלח לענן.

---

## התקנה (פעם אחת בכל מק)

**מה צריך:** מק, חיבור לאינטרנט (כ-1.5GB הורדה בפעם הראשונה בלבד), ודפדפן Chrome או Edge.

1. העתק את התיקייה `meeting-transcriber` למק (למשל לתיקיית הבית).
   אם מעתיקים ממק אחר, אפשר להשאיר בחוץ את התיקיות `.venv` ו-`recordings`.
2. לחץ **קליק ימני** על הקובץ `Install.command` ← **פתח** ← **פתח** שוב באישור.
   (macOS חוסם קבצים שהגיעו מבחוץ, ולכן בפעם הראשונה לא לוחצים לחיצה כפולה.)
3. חכה כמה דקות עד שתופיע ההודעה **All done**. ההתקנה מתקינה בעצמה את כל מה שחסר ומורידה את מודל העברית.
4. סגור את החלון.

אם ההתקנה נכשלת, בדוק את החיבור לאינטרנט והרץ את `Install.command` שוב. אפשר להריץ אותו כמה פעמים בלי בעיה.

---

## שימוש יומיומי

1. לחיצה כפולה על `Start.command`. הדפדפן נפתח לבד.
   את החלון השחור משאירים פתוח בזמן העבודה, וסוגרים אותו כשמסיימים.
2. בוחרים מה להקליט:
   - **מיקרופון:** רק הקול שלך.
   - **טאב:** הקול שמתנגן בלשונית בדפדפן, למשל Google Meet או Teams בדפדפן.
   - **טאב + מיקרופון:** כולם, אתה והמשתתפים האחרים.
3. אפשר לתת שם לפגישה ולבחור שפה (עברית, English או זיהוי אוטומטי).
4. לוחצים על הכפתור העגול להתחלה, ועליו שוב לעצירה. התמלול מתחיל לבד.
5. כשהתמלול מוכן אפשר להעתיק אותו או להוריד כ-TXT או SRT.

### הקלטת טאב – חשוב
- בחלון השיתוף שנפתח בוחרים **לשונית** (Tab), לא חלון ולא מסך.
- מסמנים את **"שתף אודיו של הלשונית"** (Share tab audio). בלי זה אין קול.
- הקלטת טאב עובדת רק ב-**Chrome** או **Edge**. ב-Safari וב-Firefox היא לא נתמכת.
- אם הפגישה רצה באפליקציה (Zoom, Teams) ולא בדפדפן, הקלטת טאב לא תקלוט אותה. פתח אותה בגרסת הדפדפן.

---

## איפה הכול נשמר

התיקייה `recordings` בתוך תיקיית הכלי: קובץ האודיו, `.txt` עם חותמות זמן, ו-`.srt`. כל ההקלטות הקודמות מופיעות גם בתחתית הדף.

---

## בעיות נפוצות

| בעיה | פתרון |
|---|---|
| macOS לא נותן לפתוח את הקובץ | קליק ימני ← פתח |
| אין קול בהקלטת טאב | לסמן "שתף אודיו של הלשונית" ולבחור לשונית |
| "לא ניתנה הרשאה" | להתיר מיקרופון ל-Chrome ב-הגדרות המערכת ← פרטיות ואבטחה ← מיקרופון |
| הדף לא נפתח | לוודא שהחלון השחור פתוח, ואז לפתוח `http://localhost:8765` |
| התמלול הראשון איטי | טעינת המודל בפעם הראשונה. הבאים מהירים יותר |
| השגיאה "address already in use" | הכלי כבר פתוח בחלון אחר. סגור אותו והפעל שוב |

---

## פרטיות

השרת מאזין רק למחשב שלך (`127.0.0.1`), והתמלול רץ מקומית. האינטרנט נדרש רק להתקנה.

---

## למתקדמים

- אין זיהוי דוברים או סיכום פגישה בגרסה הזו.
- הפעלה בטרמינל: `uv run server.py`
- תמלול קובץ קיים: `uv run transcribe.py קובץ.wav`
